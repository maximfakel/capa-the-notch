Capacity Notch 0.2.7, a beta for Apple Silicon on macOS 14 or later.

**Updating from 0.2.6:** quit the running copy, replace `CapacityNotch.app`
in Applications with the new one, and open it. macOS will likely ask for
**Open Anyway** in System Settings → Privacy & Security again, since this
build is not notarized. The permissions you granted are kept.

What's new:

- **A new onboarding.** It looks like Settings and walks through six steps:
  a welcome, permissions, Providers, Music, the Teleprompter and Dictation.
  Each Module can be switched on right there, and Dictation's model can be
  downloaded and its shortcut changed without leaving it. It speaks Russian
  with the rest of the interface. To see it again: Settings → Diagnostics →
  Run Onboarding Again.
- **Every permission at once.** Notifications, the microphone,
  Accessibility and System Events are asked for together on their own
  step, one by one or with Allow All, so no prompt interrupts work later.
- **Providers can be skipped** during onboarding and turned on later in
  Settings.

What's fixed:

- Dictation could read audio from a microphone queue that had already been
  closed when the input changed, such as a headset connecting mid-recording.
- Setting up Dictation no longer says the microphone will be asked for
  when access has already been given.
