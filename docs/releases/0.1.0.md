Capacity Notch 0.1.0 is the first beta: Codex and Claude Code Capacity in the
notch, for Apple Silicon on macOS 14 or later.

**Not signed with an Apple Developer ID and not notarized.** macOS will warn
the first time you open it, and will forget its permissions at every update.
The README's Install section has the steps — approve this one application in
System Settings → Privacy & Security; nothing here asks you to turn Gatekeeper
off.

Check the download before opening it:

```sh
shasum -a 256 -c CapacityNotch-0.1.0.zip.sha256
```

What it does:

- Codex through its own App Server; Claude Code through its own `/usage`, and
  the status-line bridge where one runs. No credential is read.
- The Headline Window in the strip, every Quota Window on the card, Stale
  Capacity kept and labelled when a refresh fails, and a reason that says
  what would fix it.
- Optional Capacity Alerts, Launch at Login, and Copy Diagnostics, which can
  carry nothing but versions, closed codes, counts and times.
- Updates by hand: **Check for Updates…** opens the latest release.

Built with `./Scripts/build-release.sh` from the tagged commit; the same
commit and Swift toolchain produce the same archive.
