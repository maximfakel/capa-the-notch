Capacity Notch 0.1.4, a beta for Apple Silicon on macOS 14 or later.

**Updating from 0.1.3:** quit the running copy, replace `CapacityNotch.app`
in Applications with the new one, and open it. macOS will likely ask for
**Open Anyway** in System Settings → Privacy & Security again, since this
build is not notarized. The permissions you granted are kept.

What's new:

- **An icon of its own.** Capacity Notch has an application icon, and its
  menu bar item is a small portrait in place of the gauge — drawn as a
  template, so it takes the menu bar's colour in light and dark.

Built with `./Scripts/build-release.sh` from the tagged commit; the same
commit and Swift toolchain produce the same archive.
