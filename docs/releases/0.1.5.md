Capacity Notch 0.1.5, a beta for Apple Silicon on macOS 14 or later.

**Updating from 0.1.4:** quit the running copy, replace `CapacityNotch.app`
in Applications with the new one, and open it. macOS will likely ask for
**Open Anyway** in System Settings → Privacy & Security again, since this
build is not notarized. The permissions you granted are kept.

What's fixed:

- **Fullscreen on macOS 27.** Over a fullscreen application the closed
  surface is the strip alone again. On macOS 27 it kept the music row over
  every fullscreen application, because the system moved some of its
  desktop windows to another process.
- **No flash on the way in.** Swiping into a fullscreen application no
  longer shows the music row for a moment before it folds away.
- **A whole archive.** Since 0.1.3 the zip flattened the links inside the
  music adapter's framework into copies and empty folders, so the bundle's
  signature did not verify, and copying a new version over the old one could
  fail. Replace the old `CapacityNotch.app` rather than copying over it.
- **Builds on macOS 27 without Xcode**, with the Command Line Tools alone.

Built with `./Scripts/build-release.sh` from the tagged commit; the same
commit and Swift toolchain produce the same archive.
