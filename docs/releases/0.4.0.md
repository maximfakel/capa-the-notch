CapaTheNotch 0.4.0, a beta for Apple Silicon on macOS 14 or later.

**Signed with the author's own certificate.** Until now every build was
signed ad-hoc, and macOS kept the microphone, Accessibility, System Events
and Calendars for any application with CapaTheNotch's identifier — so a
build someone else made could have received them without a prompt. From
this version on, each build is signed with a certificate the author holds,
and macOS keeps those permissions only for builds signed with it. It is the
author's own certificate, not Apple's: macOS still asks for **Open Anyway**
in System Settings → Privacy & Security the first time, as before.

**Updating from 0.3.1 or earlier:** the first time it opens, CapaTheNotch
clears the permissions macOS kept under the old signature, once, and opens
onboarding at Permissions to ask for them again — the microphone,
Accessibility, System Events and, with the Calendar on, Calendars. Grant
them as before; after that, updates keep them. If macOS does not let it
clear them, it says so and shows where to remove them by hand.

To check a download, in Terminal:

```sh
codesign -d -r- /Applications/CapaTheNotch.app
```

It ends with `certificate leaf = H"96f745c0374edf111dd823b633b23c9477efbba5"`,
the SHA-1 of the author's certificate; `codesign -dvv` shows
`Authority=CapaTheNotch`.

The archive is still reproducible for the author: the signature carries no
signing time, so the same commit and certificate give the same bytes, and
the release is checked that way before it is published. Anyone else can
build the same code but not the same signature — that needs the author's
key — so their archive will not match byte for byte. Building it yourself
needs a certificate of your own (`Scripts/create-signing-certificate.sh`),
and gives you your own application to macOS, with its own permissions.

What's changed:

- **Calendar.** A new Module, off until you turn it on in Settings →
  Modules; macOS asks for your calendars only then. Ten minutes before an
  event, it shows under Capacity — with Join when it carries a call link —
  and stays five minutes after it starts. When something fills the screen,
  it comes over that too, with ✕ to hide it. Open, the surface has a page
  for the day, the week and the month; with nothing left today, Kapa is
  there in sunglasses. Event titles never reach the log or Copy Diagnostics.
- **Translator.** Russian to English and English to Russian, on this Mac,
  on macOS 26 or later. Select text anywhere and press ⌃⌥T: the notch
  opens with the selection and its translation. Copy it, or — when it was
  selected in a field — put it in place of the selection with Return.
  Escape closes it and nothing is replaced. Off until turned on; macOS
  asks before downloading the two languages. Nothing translated is kept or
  logged.
- **The Teleprompter follows your voice.** Turn on Follow my voice under
  Modules → Teleprompter, and the Script moves as you read it aloud, the
  word being said lit; when you stop, it holds. It uses Dictation's speech
  model and listens only while the Script runs; nothing heard is kept.
- **Two taps on the trackpad open the notch**, from anywhere, without
  moving the pointer there. Off until turned on in Settings → General. It
  reads the trackpad through a part of macOS Apple does not publish, which a
  macOS update could close; Settings says so if it stops working.
- **Claude Code's limits from wherever it runs.** Claude Code no longer
  prints its plan's limits in `/usage`, so CapaTheNotch now offers a small
  Claude Code mod that hands them over from the terminal, VS Code and the
  Claude app's Code tab alike — asked once, added only after a yes, and
  shown in Settings → Providers with Remove. It needs Claude Code 2.1.287 or
  later; older ones keep the status line, which connecting Claude Code now
  sets up. Its Capacity reaches the notch the moment either writes, a five
  hours that has reset shows as "reset 22:40", and an idle session no
  longer overwrites a busy one's limits.
- **Settings → Providers** says why Claude Code's numbers can lag, offers
  a refresh from Terminal while the mod is not working, and has the
  compact strip's window (five hours or the week) and how often the other
  Providers are read.
