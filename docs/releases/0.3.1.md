CapaTheNotch 0.3.1, a beta for Apple Silicon on macOS 14 or later.

**Updating from Capacity Notch 0.3.0:** the application has a new name, and
so does its file. Quit Capacity Notch, delete `CapacityNotch.app` from
Applications, move `CapaTheNotch.app` there and open it. The permissions you
granted are kept, and so are your settings. macOS will likely ask for
**Open Anyway** in System Settings → Privacy & Security again, since this
build is not notarized.

If Claude Code's status line runs the bridge from `CapacityNotch.app`,
CapaTheNotch asks once, on its first launch, whether to point that path at
itself. Only after a yes does it open `~/.claude/settings.json`, and it
changes nothing else there.

What's changed:

- **Dropping a file opens the Shelf.** Carry a file towards the notch and
  it opens on the Shelf, showing where to drop it, instead of a tab
  growing under the strip. As the file comes near, Kapa grows to fill the
  drop area and eats it there. Carried elsewhere, the notch goes back as
  it was.
- **Sounds.** A few moments now have a short sound: a file taken by the
  Shelf, a Clipping copied, the notch pinned, dictated text kept or not,
  the speech model ready, a Provider that stopped answering, a Capacity
  Alert and the window recovering after it, Kapa tapped or saying hello.
  Turn them off in Settings → General; they also follow macOS's interface
  sound setting, and nothing plays while the Teleprompter runs.

The repository is now github.com/maximfakel/capa-the-notch and the site
capathenotch.tech; the old addresses lead there.
