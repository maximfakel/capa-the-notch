Capacity Notch 0.2.8, a beta for Apple Silicon on macOS 14 or later.

**Updating from 0.2.7:** quit the running copy, replace `CapacityNotch.app`
in Applications with the new one, and open it. macOS will likely ask for
**Open Anyway** in System Settings → Privacy & Security again, since this
build is not notarized. The permissions you granted are kept.

A release of fixes.

What's fixed:

- **"Five-hour" and "Weekly" in the strip** now show the window of that
  length. Before, they took a Provider's shortest and longest windows,
  which for a Provider with other windows were not five hours or a week.
- **Dictation's messages are plain sentences, in your language.** When
  text could not be inserted or pasted, the capsule could show internal
  details — process numbers, an Apple Event error code — in English.
- **An earlier Dictation error no longer hides the next one** before its
  time.
- **Dictation's shortcut shows Space and the arrows by name,** as the
  Teleprompter's does, instead of a blank or an unreadable keycap.
- **A speech model download cancelled at the very end** no longer leaves
  the 170 MB archive in the temporary folder.
- **The volume bar listens to the Mac's audio only while it is showing,**
  and not at all with the Music Module off.
