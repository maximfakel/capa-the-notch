Capacity Notch 0.1.2, a beta for Apple Silicon on macOS 14 or later.

**Updating from 0.1.1:** quit the running copy, replace `CapacityNotch.app`
in Applications with the new one, and open it. macOS will likely ask for
**Open Anyway** in System Settings → Privacy & Security again, since this
build is not notarized. It will also ask once more for any permission you had
granted — **for the last time**: from this version on, what you allow is kept
across updates.

What's new:

- **Music, optional.** Turn it on in Settings → Music. While something plays —
  in a browser, Yandex Music, Apple Music, anywhere Control Center sees — the
  strip shows it under Capacity, with previous, play/pause and next; opened,
  the surface has a page for it, with the artwork and a bar you can drag to
  seek. Swipe with two fingers to move between Capacity and music. It reads
  through a part of macOS that Apple does not publish, which an update could
  close; Settings says so if it does. It uses mediaremote-adapter (BSD
  3-Clause), credited in `THIRD_PARTY_NOTICES.md`.
- **Quitting no longer switches your Providers off.** Before, quitting from the
  menu left Codex and Claude Code disconnected, so the next start read nothing
  and showed the welcome window again.
- **Permissions are kept across updates**, as above.

Built with `./Scripts/build-release.sh` from the tagged commit; the same
commit and Swift toolchain produce the same archive.
