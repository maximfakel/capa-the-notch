Capacity Notch 0.1.1, a beta for Apple Silicon on macOS 14 or later.

**Updating from 0.1.0:** quit the running copy, replace `CapacityNotch.app`
in Applications with the new one, and open it. macOS will warn again and ask
for **Open Anyway** in System Settings → Privacy & Security, as it did the
first time: this build is not Developer ID signed or notarized, so to macOS
every version is a new application. For the same reason it may ask again for
permissions you had granted, such as notifications.

What changed:

- **Hardened Runtime.** Both of the application's executables now run under
  macOS's Hardened Runtime, with no entitlements.
- **Claude and Codex come back sooner after a failure.** A first failed read
  is tried again after 30 seconds instead of after a doubled wait. In
  particular, the first Claude reading after an update can sometimes hang;
  it used to leave Claude unread for up to ten minutes.

Built with `./Scripts/build-release.sh` from the tagged commit; the same
commit and Swift toolchain produce the same archive.
