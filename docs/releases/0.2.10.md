Capacity Notch 0.2.10, a beta for Apple Silicon on macOS 14 or later.

**Updating from 0.2.9:** quit the running copy, replace `CapacityNotch.app`
in Applications with the new one, and open it. macOS will likely ask for
**Open Anyway** in System Settings → Privacy & Security again, since this
build is not notarized. The permissions you granted are kept.

A release of fixes.

What's fixed:

- **Codex is read again with a recent ChatGPT app.** ChatGPT moved the
  Codex it carries to a new place inside itself, and Capacity Notch looks
  there now. A Codex installed with npm works too: it is started with the
  same places to look for programs as Terminal has, so it finds Node.
  Before, either case showed Codex as having no data, with a message about
  the App Server protocol that was not the real reason.
- **An image dragged off the Shelf** is written from what the drag started
  with, whatever the destination does in the meantime.
