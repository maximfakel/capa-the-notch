# Capacity Notch Hosts Built-in Modules

Capacity Notch was scoped to AI-service Capacity alone: the first glossary avoided "universal notch hub", and the spec deferred music, Shelf, clipboard, calendar and dictation until after the MVP. With the beta out, the author decided (ticket 15) that the Notch Surface hosts Modules and Capacity is the first of them — which is what was wanted from the start. Staying Capacity-only was the alternative, and a separate application for the rest does not work where it matters, because one notch cannot hold two applications' surfaces.

Four constraints come with it. Modules are built into this repository, never third-party plugins: a process that floats over every window and holds Accessibility, microphone and clipboard access should not run code nobody here wrote, and an ad-hoc signature has no chain of trust to offer; ADR 0002 applies to each Module, so boring.notch's music, Shelf and calendar are behavioural references only. Every Module but Capacity is off until a person turns it on, asks for its permissions only then, and runs nothing while off. The compact strip belongs to Capacity, except while a Module is doing something that needs attention now, such as recording or a running teleprompter. And no Module host is built ahead of need: the teleprompter is the second thing the surface shows, and the shared shape is drawn out of the two when the third arrives.

**Amended 2026-09-24 (ticket 17).** The compact strip is still Capacity's, but "except while a Module is doing something that needs attention now" is sharpened: such a Module may add a row *beneath* Capacity, never replace it. The author's mockup for music does exactly this — the strip grows from 38 to 90 points while something plays, Capacity on top. And the order changed: the author chose music first, so the Music Module is the second thing the surface shows and the teleprompter the third.

**Amended 2026-09-26 (ticket 16).** The teleprompter arrived third and the shared Module shape was not drawn out of the three: what Capacity, music and the teleprompter have in common so far is the order of the expanded surface's pages, which `SurfacePageOrder` now holds, and the rule that a running Module's row sits beneath the strip, which `TeleprompterSurface.compactRow` decides. Their rows, pages and heights still differ more than they agree, and a host drawn from three this unlike would be guessed. The author chose to wait: the shape is drawn when the fourth Module arrives.
