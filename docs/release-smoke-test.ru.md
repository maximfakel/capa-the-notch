# Проверка релиза на чистом Mac

Русская версия [release-smoke-test.md](release-smoke-test.md). Если они
расходятся, прав английский файл.

Проводится на Mac, где Capacity Notch никогда не стоял, — на отдельной машине
или в отдельной учётной записи macOS — с архивом, скачанным из релиза, а не
собранным локально. Тикет 11 закрывается этой проверкой, а не проверкой на
машине разработки.

Запишите версию macOS, SHA-256 архива и «прошло» или «не прошло» для каждого
пункта. «Не прошло» — это находка: опишите, что было видно.

Названия кнопок и меню даны так, как они выглядят в английской macOS и в
самом приложении; в русской macOS пункты системных настроек переведены.

## Установка

- [ ] В папке загрузок (`cd ~/Downloads`) `shasum -a 256 -c` для `.sha256`
      печатает `OK`, и SHA-256 совпадает с указанным в заметках к релизу.
- [ ] При первом открытии macOS показывает предупреждение «could not verify»
      («не удалось проверить») — и больше ничего.
- [ ] В System Settings → Privacy & Security есть **Open Anyway** для
      Capacity Notch; после неё и **Open** приложение запускается.
- [ ] Второе открытие не требует одобрения.
- [ ] Ни на одном шаге не предлагалось менять общесистемные настройки
      безопасности.

## Онбординг

- [ ] Окно приветствия открывается при первом запуске.
- [ ] Connect Codex читает Capacity; Connect Claude Code сначала объясняет,
      что будет делать, и только потом читает Capacity.
- [ ] Про Alerts и Launch at Login спрашивают отдельно, и они выключены, пока
      их не включить.
- [ ] После выхода и повторного запуска окно приветствия не появляется снова.

## Оба Provider'а

- [ ] В полоске у каждого Provider'а его Headline Window; на карточке — все
      Quota Window: сколько использовано и осталось, отсчёт до сброса и
      свежесть.
- [ ] Claude Code читается без открытой сессии в терминале.
- [ ] Если Codex не установлен (или во второй учётной записи без него), Codex
      говорит, как его установить, а не показывает цифры.

## Без сети

- [ ] С выключенным Wi-Fi оба Provider'а сохраняют последние цифры с пометкой
      Stale, у каждого указана причина; «Last read at» — время, когда они были
      прочитаны.
- [ ] После включения Wi-Fi оба возвращаются в Fresh без перезапуска.

## Capacity Alerts

- [ ] С включёнными Alerts окно, у которого осталось меньше 10%, присылает
      одно уведомление и не присылает второго, пока остаётся ниже порога.
      (Если ни одно окно так низко не опускалось, запишите «не проверялось».)

## Launch at Login

- [ ] Включённый в Settings, запускает приложение после выхода из учётной
      записи и повторного входа; выключенный — не запускает.

## Диагностика

- [ ] Copy Diagnostics кладёт в буфер обмена отчёт, и Settings показывает его
      же.
- [ ] В нём нет адресов почты, имени пользователя, путей внутри `/Users/` и
      токенов.

## Обновление

- [ ] **Check for Updates…** из меню и из Settings открывает последний релиз
      в браузере.
- [ ] Установка более нового архива поверх этого идёт по тем же шагам, и
      предупреждение README о забытых разрешениях совпадает с тем, что
      происходит.
